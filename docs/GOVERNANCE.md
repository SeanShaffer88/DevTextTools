# Governance

DevTextTools is a single-maintainer project.

- **Decisions** are made by the maintainer (see [MAINTAINERS.md](MAINTAINERS.md)) and recorded in [DECISIONS.md](../DECISIONS.md); the project's standing rules are in [PROJECT_RULES.md](../PROJECT_RULES.md) and the engineering-contract instantiation in [AGENTS.md](../AGENTS.md).
- **Contributions** are welcomed under [CONTRIBUTING.md](CONTRIBUTING.md); acceptance is the maintainer's call, with the registry rule (no window-only features) and the full test gate as hard requirements.
- **Releases** are never automatic: a tag and GitHub release happen only on the maintainer's explicit confirmation, and fixes are batched into grouped releases rather than shipped one at a time.
- **Scope** is fixed by the project's purpose — the tools of the ten source sites, offline, in one program. Web-dependent tools are permanently out of scope (see [COVERAGE.md](COVERAGE.md) for per-site detail); media tools are deferred, not promised.
- **Licence**: MIT (see [LICENSE](../LICENSE)). The software is free; optional donations never unlock anything, and there are no ads or in-app purchases.
